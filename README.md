# 👋 Merhabalar, Ben ApiHater

Ben 14 yaşında, siber dünyanın arka planındaki sistem mimarilerine, algoritmik yapılara ve veri akışlarına odaklanmış **Alaylı bir Siber Güvenlik Araştırmacısı ve Yazılımcıyım**. Okul sıralarında teorik terimler ezberlemek yerine; bilgisayar başında sabahlara kadar dökümantasyon tarayarak, API yapılarını çözerek ve pratik yaparak sistemlerin mutfağında yetiştim.

## 🔬 Uzmanlık ve Odak Alanlarım

*   **Tersine Mühendislik (Reverse Engineering):** Güncel tehdit aktörlerinin geliştirdiği zararlı yazılımların (.exe / malware / RAT / stealer) statik ve dinamik analizi, şifrelenmiş kod yapılarının çözülmesi (deobfuscation).
*   **Ofansif Kodlama (Malware Development):** Antivirüs imza tabanlı tarama motorlarının (firewall) çalışma mantıklarını analiz etmek ve sistem zayıflıklarını test etmek amacıyla C++ ve Python tabanlı optimizasyon araçları geliştirme.
*   **Siber Tehdit İstihbaratı (OSINT):** Açık kaynak istihbaratı mimarileri, dijital ayak izi analizi, veri korelasyonu ve komut kontrol (C2 / Webhook) mekanizmalarının tespiti.
*   **Veri ve Kitle Mühendisliği (Growth Hacking):** Sosyal medya API limitleri ve antispam algoritmaları üzerinde stres testleri. (Kendi yazdığım Python algoritmalarıyla sıfırdan 200K+ kullanıcı havuzu/user pool yönetimi deneyi).

## 🔒 Kaynak Kodları (Source Codes) Hakkında Önemli Not

Bu profil üzerindeki projelerimin kaynak kodları **bilinçli olarak kapalı (Private)** tutulmaktadır. 

Siber güvenlik etiği ve mesleki prensiplerim gereği; geliştirdiğim ofansif scriptlerin, bypass tekniklerinin ve tersine mühendislik analiz araçlarımın kaynak kodlarını internete açık (**Public**) bir şekilde paylaşmıyorum. Kodların açık kaynakta yer alması, bu tekniklerin kötü niyetli aktörler veya antivirüs imza loglama motorları tarafından suiistimal edilmesine yol açabilir.

**Ancak, siber güvenlik şirketleri, CEO'lar ve kurumsal mentörler için;**
Projelerimin çalışma mantığını gösteren **akış şemaları (flowcharts)**, terminal üzerindeki **canlı çalışma demoları (Proof of Concept)** ve analiz raporları talep doğrultusunda paylaşılabilir.
